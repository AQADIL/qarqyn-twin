# Готовность QARQYN: состояние 50 замечаний

Матрица относится к текущему коду, а не к баллам жюри. «Реализовано» означает наличие указанного механизма и связанных проверок; это не утверждение об отсутствии любых ошибок. Промышленную интеграцию, точность на заводе, причинный эффект и фактическую экономию нельзя получить заменой формулировок или синтетическими тестовыми данными.

Обозначения: **реализовано** — исправление или проверка есть в коде; **частично** — граница уменьшена, но остались конкретные условия; **внешнее подтверждение** — нужны данные, оборудование или испытание вне репозитория. Для UI и эксплуатации наличие кода отделено от подтверждённого браузерного/серверного прогона.

## Воспроизводимая проверка

```bash
npm test
npm run build
```

Браузерные сценарии и их окружение определены в `tests/e2e` и CI. Не вызывайте проверки провайдера с реальным ключом ради формального «зелёного» отчёта: автоматические тесты ИИ проверяют контракт и обработку сбоев без платных запросов.

Результат, который можно утверждать по репозиторию: модели и рабочие операции имеют определённые контракты, проверки и объяснённые ограничения. Результат, для которого нужны внешние свидетельства: точность на предприятии, снижение аварийности, фактически выполненный план, причинный прирост и финансовая экономия.
