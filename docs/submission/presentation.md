# QARQYN · презентация на три минуты

[PDF для отправки](QARQYN-pitch.pdf) · [HTML для показа](QARQYN-pitch.html) · [Реплики для двух участников](presentation-notes.md) · [Вопросы жюри](pitch-and-qa.md)

Шесть слайдов в формате 16:9: производственная задача, рабочий продукт, обратное планирование, частичное выполнение и предложение пилота. Чёрный фон, звёзды и космические иллюстрации продолжают тёмную тему приложения; данные и расчёты относятся к автомобильному производству Allur.

Для выступления достаточно PDF. HTML можно скачать и открыть в браузере без сервера и интернета: изображения и шрифты встроены. Каждый слайд занимает отдельный экран и автоматически масштабируется до размеров окна с сохранением пропорций 16:9. На экранах с другим соотношением сторон остаются чёрные поля, чтобы текст не обрезался. Стрелки, Page Up / Page Down и пробел переключают слайды; панель внизу включает полный экран и печать и скрывается после паузы. Движение указателя или нажатие клавиши снова показывает управление.

## Обновить и экспортировать

Из корня репозитория с Node.js 22.13 или новее:

```sh
npm ci
npx playwright install chromium
node scripts/export-pitch.mjs
```

Редактируемый макет: [presentation.template.html](presentation.template.html). Скрипт собирает автономный HTML и экспортирует PDF через Chromium. Все вычисляемые значения берутся из [исходного набора Allur](../../data/allur.json), [модели потока](../../server/analytics.js) и [расчёта частичной реализации](../../server/impact.js). Цель 109, горизонт 8 часов, длительность исходной строки 8 часов и реализация 50% заданы как условия демонстрации. Они не являются производственным заданием предприятия.

Перед новой отправкой проверьте все шесть страниц PDF и соответствие речи. При изменении данных нужно также обновить скриншот, подписи источников и реплики.

## Визуальные материалы

Слайды используют собственные иллюстрации проекта `cosmic-hero`, `cosmic-painting`, `cosmic-welding`, `cosmic-finished`, реальный снимок экрана `overview-dark.png` и шрифт IBM Plex Sans. Иллюстрации и звёздный фон созданы с ИИ.

Фон `docs/assets/pitch-stars.jpg` создан для этой презентации по следующему описанию: чистый чёрный широкоформатный фон, редкие мелкие белые и тёплые звёзды, едва заметная пыль цвета шампанского только у правого края, свободная левая часть для крупного текста, без планет, ракет, логотипов, синего и фиолетового оттенков.
